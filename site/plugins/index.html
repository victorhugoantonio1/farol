Plugins

Cada plugin liga o TopWatch a outro sistema e ganha uma aba na barra e uma seção nas configurações. O Zabbix já vem no app.

  • G

    GLPI

    Aba Chamados com os chamados não solucionados, ordenados por prioridade. Mostra só os seus, se você quiser, e abre o chamado com um clique.

    Funciona com a API REST do GLPI 9.5, 10 e 11. Entra em todas as entidades com subentidades e aceita token de usuário de serviço.

    Disponível na edição para equipes Pedir o plugin
  • Pr

    Prometheus Alertmanager e Grafana

    Alertas do Alertmanager e do Grafana Alerting junto com os do Zabbix, com o botão Reconhecer criando um silêncio.

    Planejado para a API v2 do Alertmanager, que o Grafana Alerting também usa.

    Planejado
  • P

    PRTG

    Sensores em alerta e com erro do PRTG Network Monitor na lista de alertas.

    Planejado
  • D

    Datadog

    Monitores em alerta do Datadog, com a severidade de cada um.

    Planejado

Como instalar um plugin

  1. Extraia o plugin

    O plugin chega como um .zip. Extraia num lugar qualquer: dentro dele tem uma pasta com um arquivo index.js.

  2. Instale pelo TopWatch

    No ícone da bandeja, abra Configurações. Em Plugins, clique em Instalar plugin e escolha essa pasta.

  3. Ative e teste

    A seção do plugin aparece nas configurações, sem reiniciar. Preencha, use Testar conexão e salve.

Crie o seu plugin

Um plugin é uma pasta com um index.js. Ele declara a aba e os campos de configuração e devolve os itens a mostrar. O TopWatch cuida da tela, da criptografia dos tokens e da coleta.

module.exports = {
  apiVersion: 1,
  id: 'meu-sistema',
  name: 'Meu Sistema',
  tab: { label: 'Tarefas', singular: 'tarefa', plural: 'tarefas' },
  fields: [
    { key: 'url', type: 'url', label: 'URL' },
    { key: 'token', type: 'secret', label: 'Token' }, // salvo criptografado
  ],
  create(ctx) {
    return {
      async fetch(cfg) {
        // busque na API com ctx.request e devolva os itens
        return [{ id: 1, title: 'Backup falhou', level: 4, levelLabel: 'Alta', url: 'https://…' }];
      },
      async test(cfg) { return 'Conectado.'; },
    };
  },
};

O formato completo está descrito no começo de src/plugins.js. Plugins rodam com acesso ao computador: instale só os de quem você confia.
